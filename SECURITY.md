# Security Policy

fsociety-browser is alpha software. **Do not rely on it where your safety depends on anonymity — use [Tor Browser for Android](https://www.torproject.org/download/#android) for that.**

## Reporting a vulnerability

Please report leaks (DNS, WebRTC, proxy bypass, fingerprinting regressions, data left on disk) privately through
GitHub's *Security → Report a vulnerability* on this repository instead of opening a public issue.
Include the GeckoView version, Android version, device, and steps to reproduce.
